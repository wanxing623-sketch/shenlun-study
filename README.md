# 申论词库 · 学习工作台 V2

一个基于本地资料构建的申论学习工作台，纯静态网页，可直接部署到 GitHub Pages，离线可用。

## 功能

**资料库**
- 规范词库：420 条（21 期积累，按场景分类筛选）
- 对策库：70 条对策模板 + 72 条常见问题表述（双视图互相对照）+ 对策组合器
- 案例图谱：560 条（7 章 56 个主题小节）
- 公文速查：24 种文种结构 + 排版例文（与结构说明并排）+ 交卷检查清单

**实战**
- 真题作答台：内置 253 套国考/省考申论真题（约 166 万字）
  - 恒定左右 50/50 分栏：左边材料、右边题目+作答，可边标注边作答
  - 材料按试卷方式**横向翻页**阅读（滚轮/触摸拖动/翻页按钮），段落首行缩进，模拟纸质卷
  - 点击句子或划选文字进行四色标注（含橡皮），标注即时保存、翻页不丢失；标注按卷保存，切换试卷不会被清掉
  - 实时字数统计、输入后 600ms **自动保存**、离开页面/切后台立即落盘、180 分钟考试倒计时（按卷独立计时）；作答、标注、批改结果都按「卷 + 题」分开保存，切卷切题都不丢
  - **字数上下限自动识别**：题干/要求里写明的「不超过 300 字」「1000～1200 字」「不少于 800 字」都会被解析，超上限的格子标红、不足下限会提示，不再出现「字数不限」的误判
  - 少数把同一年多套卷合并的省考数据里题号重复（两套卷都有「第 2 题」），作答与批改改用题序作键，不再互相覆盖；完全重复的题目自动去重
  - **AI 式多阅卷官批改**：写完点击「提交批改」，五位阅卷官（采点覆盖 / 结构逻辑 / 规范表达 / 格式卷面 / 深度论证）按题型加权联评，给出分数、等级、逐项问题与建议、优先改进 Top 4；评分知识取自开源考公项目（SLB 批改标准 / kaogong-skill 题型标准 / kaogong-formalizer 113 条口语→规范词映射），纯本地规则引擎，批改结果按卷按题保存、可一键复制完整报告
  - **参考答案 + 要点自检**：按「试卷 ID + 题序」把 4 个 GitHub 开源题库（gwy-zhenti / gongkao-tiku / 国考机构解析 / zhenti-knowledge）的答案逐题匹配进来（题干相似度 + 材料重合度双重校验，**974 / 981 题有答案**，其余如实标「暂无」）；作答并批改后可查看多来源答案，自动比对哪些采分点已写到、可手动勾选修正，实时给出自评覆盖率与估算分，查看记录与勾选结果按「卷 + 题」保存
  - 参考答案不硬编码题号：匹配脚本在 `tools/answers/build_answers.py`，说明见 `tools/answers/README.md`；答案按组打包为 `exams/answers-{gk,prov1,prov2}.js`，切卷时按需加载，不影响首屏

**练习室**
- 短材料小题 327 道：概括 / 分析 / 对策，按年份与题型筛选，材料单独折叠阅读
  - 分条作答，交卷后按**要点覆盖**批改：逐条对照参考答案、标出漏掉的要点、低于 80 分时自动展开对照面板
  - 12 道人工精析题附采分关键词，批改改为关键词命中 + 逐项标绿标红
- 大作文拆解 119 篇：整卷材料 + 原卷作文题，只写标题 / 三条分论点 / 收尾句
  - 边写边做**结构检查**（起手字是否重复、长短是否雷同、有无高频滥词、“不是……而是……”是否滥用、有无具体物象）
  - 交卷后按关键词 + 结构加权打分，并给出参考标题、分论点、收尾句、题库范文、本题失分点与审题思路
- 标题分论点训练 8 组：限时出标题 + 三个分论点 + 收尾句，配骨架提示、练点与范文片段
- 写作素材库：147 句金句、57 个案例、30 组规范表述、58 组滥词替换、27 张行文骨架，可搜索、按主题筛选、★ 收藏
- 我的练习：已练题目、平均得分率、连续打卡、最近 12 次成绩、按得分自动排期的复习清单、收藏、导出 / 导入 / 清空
- 作答保护：输入即自动保存（合并写入，离开页面强制落盘）；从别的页面切回来仍停在原来的作答页；只“看答案”没写内容不会记成 0 分练习；草稿纸内容不计入要点评分；大作文分块作答也会显示总字数
- 顶栏全局搜索已接入练习室题库与素材（结果标注“小题 / 大作文 / 训练 / 金句 / 案例”），点一下直达对应题目
- 数据与脚本：`exams/lab/lab-data.js`（题库与素材）、`exams/lab/lab.js`（模块逻辑）、`exams/lab/lab.css`（样式，复用本项目设计令牌，深浅色自动适配）
- 练习室数据独立保存在 `sh_lab_v1` 键，不影响原有收藏、笔记与作答记录

**作答与标注（两个做题模块通用）**
- **作答区升级：标准作文方格纸**。每格一字、每段首行自动缩进两格、回车分段；**点哪一格就从哪一格写**——点有字的格插在该字之前、点段首缩进格回到该段开头、点正文下方的空白格接着往下写，不会再出现“点了没用”或光标乱跳
- **只有一个光标，跟着格子走**：方格纸里原来会同时出现「原生输入框的细竖线」和「格子高亮」两个光标，现在原生插入符已隐藏，只剩一格闪烁的方块光标；光标只在将要跑出可视区时才滚动最小距离，不再整块纸上下猛拉
- 组字时的拼音/候选显示成贴着光标的小字条（不是弹窗）；提示文案只在状态变化时更新，同样的 toast 1.5 秒内只弹一次；输入采用增量重绘（只改动真正变化的格子），长答案连打也不卡
- **材料标注画笔全模块可用**。四色笔 + 橡皮，点击整句标注 / 划选精确到字 / 同色再点取消；同一句反复改色只算 1 处、擦掉即减 1 处（标注指令自动压缩，不会越积越多）；练习室的短材料、大作文整卷材料都能标注，标注按题保存；移动端把画笔收进右下角悬浮条，不遮挡正文

**巩固**
- 复习中心：待复习 / 已掌握 / 收藏 / 笔记 四合一
- 内嵌 10 题快闪训练，自评结果回写掌握状态

**体验（人因设计）**
- 跨浏览器兜底：iOS Safari（含 100dvh 缺失、安全区、输入框自动放大）、旧版 Android WebView（不用正则后行断言 / 可选链）、Firefox（滚动条样式与 overscroll 行为）均可用
- 深色模式（跟随系统或手动切换，夜间学习友好）
- 正文对比度满足 WCAG AA；焦点态清晰
- 响应式：桌面 / 平板（768-1024）/ 手机（≤760）/ 小屏（≤380）四档布局，另有手机横屏专门处理；移动端底部标签栏 + 抽屉导航，窄屏搜索框收成图标点开展开
- 触屏设备自动放大点击目标；支持「大字号」「减少动画」
- 数字键 1–9 快速切换页面，Ctrl/⌘ K 全局搜索

## 本地运行

直接双击 `index.html`；或在当前目录执行：

```bash
python3 -m http.server 4173
```

访问 http://localhost:4173。

## 部署到 GitHub Pages

1. GitHub 新建仓库（例如 `shenlun-study`）。
2. 上传 `index.html`、`data/`、`exams/`、`.nojekyll`、`README.md` 到仓库根目录。
3. Settings → Pages → Deploy from a branch → main / (root) → Save。
4. 访问 `https://你的用户名.github.io/shenlun-study/`

## 数据说明

学习记录（收藏、掌握状态、真题标注与作答、笔记）仅保存在本机浏览器 localStorage。
请在「设置」中定期导出 JSON 备份，换设备时导入恢复。
