# 真题数据来源与处理说明

本目录下的真题数据用于「申论词库 · 写作训练台」的**真题作答台**功能。

## 来源

- 原始语料抓取自公开学习网站 shenlunhome.com，经 GitHub 开源仓库
  [Jinghe1279/SLB](https://github.com/Jinghe1279/SLB)（`data/shenlun_zhenti/`）整理为 Markdown。
- 在此基础上由本仓库脚本清洗、解析为结构化 JSON，并打包为 `index.js / gk.js / prov1.js / prov2.js`。

## 内容

- 共 253 套申论真题（约 166 万字）：
  - 国考 18 套（2011–2026，副省级 / 地市级 / 行政执法）
  - 33 个省区市省考卷（上海、江苏、浙江、山东、广东、四川、北京等）
- 每套包含：材料（按「资料 N」分节、分段）+ 作答要求（题干、要求、分值、字数限制）。
- 部分年份/卷别存在缺漏（原始数据源本身缺失，如 2016、2018、2019、2024 年国考部分卷种）。

## 处理原则

- 仅保留题目材料与作答要求；源文件标题中的「含参考答案」字样已去除，数据中不含参考答案。
- 剔除了源数据中的乱码/占位文件、招警与政法干警等非普通公务员考试卷。
- 解析脚本为一次性处理（未随仓库分发），如需更新数据可参照上仓库重新生成。
