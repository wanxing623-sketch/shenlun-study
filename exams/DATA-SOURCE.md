# 真题数据来源与处理说明

本目录下的真题数据用于「申论词库 · 写作训练台」的**真题作答台**功能。

## 一、题目与材料

- 原始语料抓取自公开学习网站 shenlunhome.com，经 GitHub 开源仓库
  [Jinghe1279/SLB](https://github.com/Jinghe1279/SLB)（`data/shenlun_zhenti/`）整理为 Markdown。
- 在此基础上由本仓库脚本清洗、解析为结构化 JSON，并打包为 `index.js / gk.js / prov1.js / prov2.js`。
- 共 253 套申论真题（约 166 万字）：
  - 国考 18 套（2011–2026，副省级 / 地市级 / 行政执法）
  - 33 个省区市省考卷（上海、江苏、浙江、山东、广东、四川、北京等）
- 每套包含：材料（按「资料 N」分节、分段）+ 作答要求（题干、要求、分值、字数限制）。
- 部分年份/卷别存在缺漏（原始数据源本身缺失，如 2016、2018、2019、2024 年国考部分卷种）。
- 题目数据本身**不含参考答案**；答案单独打包，见下一节。

## 二、参考答案（按「试卷 ID + 题序」匹配）

参考答案来自以下公开 GitHub 仓库，由 `tools/answers/build_answers.py` 抓取、清洗并按题匹配：

| 仓库 | 内容 | 用途 |
| --- | --- | --- |
| [ProfessorZhi/gwy-zhenti](https://github.com/ProfessorZhi/gwy-zhenti) | 粉笔题库整理的历年国考 / 省考申论真题 + 参考答案、解析 | 主来源（925 份卷 / 3527 题） |
| [zzcc-nb/gongkao-tiku](https://github.com/zzcc-nb/gongkao-tiku) | 申论题库，含粉笔参考答案与答题演示 | 按题干检索补缺 |
| [h1neolzr7f/guokao-real-exams-2022-2026](https://github.com/h1neolzr7f/guokao-real-exams-2022-2026) | 2022–2026 国考三卷机构解析（答案 / 评分标准 / 范文） | 2026 国考多来源对照 |
| [36hxqw/gongkao-zhenti-knowledge](https://github.com/36hxqw/gongkao-zhenti-knowledge) | 国考 / 广东 / 湖北真题结构化数据与答案 | 补缺与交叉验证 |

匹配规则（详见 `tools/answers/README.md`）：

1. 题干规范化后计算字符二元组 Dice 相似度；
2. 来源试卷逐节材料在本项目整卷材料中的覆盖率（按节长度加权）；
3. 两者同时达标才落库，按 `high / mid / loose` 标注置信度，防止「题号相同但卷子不同」串答案；
4. 与前端去重逻辑一致，按「试卷 ID + 题序（数组下标）」对齐；题号只作兜底；
5. 同一答案的多来源、同源「参考答案一 / 二 / 三」都会保留在「其他来源答案」中对照。

当前覆盖：**974 / 981 题（99.3%）**，251 套整卷全覆盖；其余 7 道题在四个开源题库中均无可靠答案，页面会明确显示「暂无参考答案」，不硬凑、不生成假答案。

> 以上答案均为机构 / 考生整理版，**不是官方标准答案**。表述、要点拆解与真实阅卷会有差异，请以材料和题干为准。

## 三、处理原则

- 题目数据仅保留材料与作答要求；源文件标题中的「含参考答案」字样已去除。
- 参考答案独立放在 `answers-*.js`，按真题分组懒加载，不影响首屏体积。
- 剔除了源数据中的乱码/占位文件、招警与政法干警等非普通公务员考试卷。
- 题目解析脚本为一次性处理（未随仓库分发），如需更新题目可参照上仓库重新生成；答案可用 `tools/answers/build_answers.py` 重建。

## 四、用途声明

真题文本与参考答案版权归原命题机构 / 整理者所有，本仓库仅作个人学习研究之用，请勿用于商业用途。
如来源仓库要求删除相关内容，请删除 `exams/answers-*.js` 并停止运行答案构建脚本。
