# 真题数据来源与处理说明

本目录下的真题数据用于「申论词库 · 写作训练台」的**真题作答台**功能。

## 一、题目与材料

- 原始语料抓取自公开学习网站 shenlunhome.com，经 GitHub 开源仓库
  [Jinghe1279/SLB](https://github.com/Jinghe1279/SLB)（`data/shenlun_zhenti/`）整理为 Markdown。
- 由 `tools/exams/build_exams.py` 解析重建：材料按「材料一 / 材料1：」两种写法切分，
  作答要求按题切分，多卷合并的源文件（如浙江 A/B/C 卷）按卷签拆分，子问题（「回答下列两个问题」）合并回同一题。
  重建后打包为 `index.js / gk.js / prov1.js / prov2.js`。
- 每道题的题干、材料引用、材料正文都来自同一份源文件、同一套卷，材料引用超出本书材料数量时会报错拦截。
- 共 253 套申论真题（约 166 万字）：
  - 国考 18 套（2011–2026，副省级 / 地市级 / 行政执法）
  - 33 个省区市省考卷（上海、江苏、浙江、山东、广东、四川、北京等）
- 每套包含：材料（按「资料 N」分节、分段）+ 作答要求（题干、要求、分值、字数限制）。
- 部分年份/卷别存在缺漏（原始数据源本身缺失，如 2016、2018、2019、2024 年国考部分卷种）。
- 题目数据本身**不含参考答案**；答案单独打包，见下一节。

## 二、参考答案（按「试卷 ID + 题序」匹配）

参考答案来自以下公开 GitHub 仓库，由 `tools/answers/build_answers.py` 抓取、清洗并按题匹配：

| 仓库 | 内容 | 用途 |
| --- | --- | --- |
| [ProfessorZhi/gwy-zhenti](https://github.com/ProfessorZhi/gwy-zhenti) | 粉笔题库整理的历年国考 / 省考申论真题 + 参考答案、解析 | 主来源（925 份卷 / 3527 题） |
| [zzcc-nb/gongkao-tiku](https://github.com/zzcc-nb/gongkao-tiku) | 申论题库，含粉笔参考答案与答题演示 | 按题干检索补缺 |
| [h1neolzr7f/guokao-real-exams-2022-2026](https://github.com/h1neolzr7f/guokao-real-exams-2022-2026) | 2022–2026 国考三卷机构解析（答案 / 评分标准 / 范文） | 2026 国考多来源对照 |
| [36hxqw/gongkao-zhenti-knowledge](https://github.com/36hxqw/gongkao-zhenti-knowledge) | 国考 / 广东 / 湖北真题结构化数据与答案 | 补缺与交叉验证 |

匹配规则（详见 `tools/answers/README.md`）：

1. 题干规范化后计算字符二元组 Dice 相似度；
2. 来源试卷逐节材料在本项目整卷材料中的覆盖率（按节长度加权）；
3. 两者同时达标才落库，按 `high / mid / loose` 标注置信度，防止「题号相同但卷子不同」串答案；
4. 匹配按题干在**整卷范围**内取最像的一题，题号只作加分，题序错位也不会串答案；
5. 答案落库时拆成三段：`a` 参考答案正文、`note` 参考答案说明（解析性质，页面折叠展示）、
   `x`/`k` 解析与考点；同源「参考答案一 / 二 / 三」「参考范文」放入「其他版本」对照。

当前覆盖：**949 / 981 题（96.7%）**，高置信 931 题、中等置信 16 题。尚未覆盖的 32 题集中在
新疆 2013/2014/2018/2019/2021、河南 2014、联考 2012/2013 等卷，公开题库里没有对应答案，
页面会明确显示「暂无参考答案」，不硬凑、不生成假答案。

> 以上答案均为机构 / 考生整理版，**不是官方标准答案**。表述、要点拆解与真实阅卷会有差异，请以材料和题干为准。

## 三、处理原则

- 题目数据仅保留材料与作答要求；源文件标题中的「含参考答案」字样已去除。
- 参考答案独立放在 `answers-*.js`，按真题分组懒加载，不影响首屏体积。
- 剔除了源数据中的乱码/占位文件、招警与政法干警等非普通公务员考试卷。
- 题目解析脚本见 `tools/exams/build_exams.py`（`--src` 指向上游 `data/shenlun_zhenti` 目录，`--report` 打印缺口与越界告警）；
  参考答案用 `tools/answers/build_answers.py` 重建；结构化审计见 `tools/audit/audit_exams.js`。

## 四、资料库语料（规范词 / 对策 / 问题表述 / 公文）

资料库页面的结构化数据放在 `tools/library/`，由 `tools/library/build_library.py` 生成前端离线文件：

- `data/formats.js`（`window.SH_FORMATS`）：**24 种公文文种**，分 3 组——法定公文 9 种（意见、通知、报告、请示、批复、函、通告、通报、会议纪要）、事务文书 9 种（调研报告、工作方案、简报、汇报提纲、建议书、情况说明、启事、主持词、讲话稿）、宣传沟通 6 种（公开信、宣传稿、倡议书、编者按、短评、致辞）。每种含结构拆解、落笔提醒、检查清单与一份按答题纸版式排好的例文。
- `data/problems.js`（`window.SH_PROBLEMS`）：**72 条常见问题表述**，按 9 类治理场景分组（宣传引导、制度监管、数字赋能、人才队伍、资金产业、协同治理、疏堵结合、权益保障、基础设施），每条含规范表述、材料信号词与可对应对策。

语料来源：

| 仓库 | 内容 | 用途 |
| --- | --- | --- |
| [zzcc-nb/gongkao-tiku](https://github.com/zzcc-nb/gongkao-tiku) | `智能系统/规范词大全/问题类规范词.md`、`对策类规范词.md`、`公文规范用语.md` | 问题表述与公文用语的主来源；按申论作答习惯筛选、改写，剔除评分说明等噪声 |
| 本仓库整理 | 对策模板、公文文种结构、例文 | 在开源语料基础上按考试场景重写与补全 |

重建命令：

```bash
python3 tools/library/build_library.py
```

脚本会校验文种重名、必填字段、分组与对策 ID 连续性，并自动补 `index.html` 中的 `data/*.js` 引入标签。**不要手改 `data/formats.js` / `data/problems.js`**，改 `tools/library/*.json` 后重新生成。

真题文本与参考答案版权归原命题机构 / 整理者所有，本仓库仅作个人学习研究之用，请勿用于商业用途。
