# 申论词库 · 学习工作台 V2

一个基于本地资料构建的申论学习工作台，纯静态网页，可直接部署到 GitHub Pages，离线可用。

## 功能

**资料库**
- 规范词库：420 条（21 期积累，按场景分类筛选）
- 对策库：70 条模板 + 对策组合器
- 案例图谱：560 条（7 章 56 个主题小节）
- 公文速查：9 种文种结构 + 交卷检查清单

**实战**
- 真题作答台：内置 253 套国考/省考申论真题（约 166 万字）
  - 恒定左右 50/50 分栏：左边材料、右边题目+作答，可边标注边作答
  - 材料按试卷方式**横向翻页**阅读（滚轮/触摸拖动/翻页按钮），段落首行缩进，模拟纸质卷
  - 点击句子或划选文字进行四色标注（含橡皮），标注即时保存、翻页不丢失
  - 实时字数统计、自动保存、180 分钟考试倒计时；**切换试卷时标注自动清零**（每套卷从干净卷面开始）；作答内容仍按卷独立保存
  - **AI 式多阅卷官批改**：写完点击「提交批改」，五位阅卷官（采点覆盖 / 结构逻辑 / 规范表达 / 格式卷面 / 深度论证）按题型加权联评，给出分数、等级、逐项问题与建议、优先改进 Top 4；评分知识取自开源考公项目（SLB 批改标准 / kaogong-skill 题型标准 / kaogong-formalizer 113 条口语→规范词映射），纯本地规则引擎，批改结果按卷按题保存、可一键复制完整报告

**巩固**
- 复习中心：待复习 / 已掌握 / 收藏 / 笔记 四合一
- 内嵌 10 题快闪训练，自评结果回写掌握状态

**体验（人因设计）**
- 深色模式（跟随系统或手动切换，夜间学习友好）
- 正文对比度满足 WCAG AA；焦点态清晰
- 响应式：桌面 / 平板 / 手机三档布局；移动端底部标签栏 + 抽屉导航
- 触屏设备自动放大点击目标；支持「大字号」「减少动画」
- 数字键 1–8 快速切换页面，Ctrl/⌘ K 全局搜索

## 本地运行

直接双击 `index.html`；或在当前目录执行：

```bash
python3 -m http.server 4173
```

访问 http://localhost:4173。

## 部署到 GitHub Pages

1. GitHub 新建仓库（例如 `shenlun-study`）。
2. 上传 `index.html`、`exams/`、`.nojekyll`、`README.md` 到仓库根目录。
3. Settings → Pages → Deploy from a branch → main / (root) → Save。
4. 访问 `https://你的用户名.github.io/shenlun-study/`

## 数据说明

学习记录（收藏、掌握状态、真题标注与作答、笔记）仅保存在本机浏览器 localStorage。
请在「设置」中定期导出 JSON 备份，换设备时导入恢复。
