# 真题数据来源与处理说明

本目录下的真题数据用于「申论词库 · 学习工作台」的**真题作答台**功能。

## 来源

- 原始语料抓取自公开学习网站 shenlunhome.com，经 GitHub 开源仓库
  [Jinghe1279/SLB](https://github.com/Jinghe1279/SLB)（`data/shenlun_zhenti/`）整理为 Markdown。
- 在此基础上由本仓库脚本 `tools/parse_slb_exams.py` 清洗、解析为结构化 JSON（默认只做 dry-run，
  加 `--write` 写出 `tools/_new_exams.json`），再由 `tools/merge_new_exams.py` 合并进本目录。
- 分组文件：`gk.js`（国考）、`prov1.js` / `prov2.js`（原有省考）、`prov3.js`（本次新增省考），
  索引为 `index.js`，页面按分组**懒加载**。

## 内容

- 共 **278 套**申论真题（约 **182 万字**）：
  - 国考 18 套（2011–2026，副省级 / 地市级 / 行政执法）
  - 33 个省区市省考卷（上海、江苏、浙江、山东、广东、四川、北京等），合计 34 个地区
  - 其中本次新增 25 套（14 个地区，约 15.8 万字），见 `prov3.js`：
    内蒙古 2017、吉林 2014/2015/2017/2018、天津 2014/2017、安徽 2018 A 卷 / B 卷、安徽 2022 B 卷、
    山东 2015 B 类 / 2023 A 类 / 2024 A 类、山西 2018 乡镇卷、广东 2022 乡镇、河北 2018 联考乡镇 / 2019 县级、
    河南 2016、浙江 2019 A+B 卷、深圳 2022 一卷二卷、湖北 2023 县乡卷 / 2024 省市卷 / 2024 选调生卷、
    湖南 2023 省市卷、辽宁 2024 B 类。
- 每套包含：材料（按「材料 N」分节、分段）+ 作答要求（题干、要求、分值、字数限制）。
- 部分年份/卷别存在缺漏（原始数据源本身缺失，如 2016、2018、2019、2024 年国考部分卷种）；
  联考卷在多个省份分别发布时会有内容相同的版本（如 2018 山西与河北乡镇卷），按原始标题保留各自条目。
- 新增卷 id 一经写入不再改动（作答记录以 id 为键），如需调整请只追加、不重命名。
  本次仅有 1 处改名：`湖北_2024_主卷` → `湖北_2024_选调生卷`（该卷尚未有作答记录）。

## 处理原则

- 仅保留题目材料与作答要求；源文件标题中的「含参考答案」字样已去除，数据中**不含参考答案**。
- 剔除了源数据中的乱码/占位文件、招警与政法干警等非普通公务员考试卷。
- 校验规则：3–8 题、材料 1–16 节、材料正文不少于 2000 字、每题有分值、总分 80–160 分。
- 解析脚本随仓库分发：`tools/parse_slb_exams.py`、`tools/merge_new_exams.py`（用法见 `tools/README.md`）。
